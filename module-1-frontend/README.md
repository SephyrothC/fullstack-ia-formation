# 🧱 Module 1 – Développement Web Frontend

🎯 **Objectif** : Créer une interface web moderne et responsive

---

## 📚 Contenu du module

- HTML sémantique & accessibilité
- CSS moderne : Flexbox, Grid, animations de base
- JavaScript DOM & logique d’interaction
- Introduction à **React** :
  - Composants fonctionnels
  - Props & State
  - JSX et gestion des événements

---

## 🎓 Certifications recommandées

- [FreeCodeCamp – Responsive Web Design](https://www.freecodecamp.org/learn/2022/responsive-web-design/)
- [FreeCodeCamp - Front End Development Libraries](https://www.freecodecamp.org/learn/front-end-development-libraries/)

---

## 🛠️ Projet pratique

- **Mini-portfolio** avec React
  - Page d'accueil, section compétences, projets, contact
  - Design responsive et moderne
