# 🧭 Cours 0 : Introduction

📅 **Durée** : 0,5 mois
🎯 **Objectif** : Acquérir les bases de la programmation, des outils et de l’environnement de développement.

---

## 🛠️ Contenu du module

### 1. Installation et configuration

* ✅ Installer [VS Code](https://code.visualstudio.com/)
* ✅ Ajouter les extensions recommandées (Python, GitLens, etc.)
* ✅ Configurer le terminal intégré
* ✅ Installer [Python](https://www.python.org/downloads/)

### 2. Premier pas avec Python

* ✨ Objectif : Écrire, exécuter et comprendre un script Python simple
* Exemple guidé :

```python
name = input("Quel est ton nom ? ")
print(f"Bonjour, {name} ! Bienvenue dans le cours.")
```

### 3. Introduction au terminal

* 📚 Apprentissage des commandes de base :

  * `ls`, `cd`, `mkdir`, `touch`
  * `python script.py`
  * `git init`, `git status`

### 4. Certification à valider (TP)

> ✅ Suivre la formation [Python for Everybody – freeCodeCamp](https://www.freecodecamp.org/learn/python-for-everybody/)

* Format : 56 modules avec vidéo + exercices
* Thèmes abordés :

  * Bases du langage
  * Structures de données
  * Fonctions, boucles, conditions
  * Expressions régulières
  * Web scraping, API, objets
  * SQLite et visualisation de données

### 5. Projet final (mini TP)

> 🎯 Créer un script Python lisant un fichier texte et comptant le nombre de mots les plus fréquents.

Exemple de rendu attendu :

```bash
python analyseur.py fichier.txt
```

Affichage :

```
1. "le" → 153 fois
2. "de" → 140 fois
3. "et" → 128 fois
...
```
