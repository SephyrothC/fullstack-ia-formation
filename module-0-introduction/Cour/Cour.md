# 🧭 Module 0 – Introduction

📅 **Durée** : 0,5 mois  
🎯 **Objectif** : Poser les bases numériques, de la logique algorithmique et de la programmation  
💡 **Public cible** : Grand débutant (aucune base nécessaire)

---

## 🌟 Compétences visées

| Domaine       | Objectifs                                                                      |
| ------------- | ------------------------------------------------------------------------------ |
| Numérique     | Comprendre le fonctionnement d’un système d’exploitation, utiliser le terminal |
| Programmation | Maîtriser la logique, les variables, et écrire ses premiers scripts            |
| GitHub        | Créer un compte, comprendre les bases du versionnement                         |
| Algorithmie   | Débuter avec le langage C pour comprendre les structures fondamentales         |

---

## 🧰 Outils et technologies

- Google Drive (gestion de fichiers)
- GitHub (versionnement)
- VS Code (éditeur de code)
- Terminal (commande de base)
- Compilateur C : gcc
- Navigateur : Chrome ou Firefox

## 🧪 Cours & Exercices par étapes

### 1. 🌍 Bases informatiques

| Objectif                                | Activités                                                                 |
| --------------------------------------- | ------------------------------------------------------------------------- |
| Comprendre ce qu’est un OS, un terminal | Visionnage de vidéos CS50 + test de commandes Linux (mkdir, cd, ls, etc.) |
| Créer un compte GitHub et un dépôt      | Tuto guidé de prise en main GitHub                                        |
| Prise en main de VS Code                | Installer, créer un projet, installer des extensions utiles               |

---

### 2. 🧠 Logique de programmation

| Objectif                                      | Activités                                  |
| --------------------------------------------- | ------------------------------------------ |
| Comprendre les variables, conditions, boucles | Exercices guidés en JS puis en C           |
| Expliquer ce qu’est un algorithme simple      | Fiches logiques + petits schémas           |
| Savoir traduire un problème en code           | Exercice guidé “convertisseur température” |

---

### 3. 🔣 Initiation au langage C

| Objectif                                     | Activités                                                       |
| -------------------------------------------- | --------------------------------------------------------------- |
| Compiler et exécuter un programme en C       | Installation de gcc + premier hello.c                           |
| Manipuler les variables, les if, les boucles | Petits scripts éducatifs                                        |
| Comprendre le typage statique                | Comparaison entre JS et C sur les types                         |
| Créer une structure de programme propre      | Utilisation de fonctions simples (`int calculer(int a, int b)`) |
