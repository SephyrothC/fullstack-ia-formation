# 🎓 Module 7 – Projet Final & Portfolio

🎯 **Objectif** : Rassembler toutes les compétences dans un projet cohérent

---

## 📚 Contenu du module

- Choisir un thème personnel ou pro
- Créer une stack complète : Frontend + Backend + IA
- Documenter le projet + publier un portfolio

---

## 🎓 Certifications suggérées

- Meta Fullstack Developer – Coursera
- Microsoft AI Engineer (si toutes les compétences sont validées)

---

## 🛠️ Projet final

- Site React + API Node/FastAPI + IA intégrée
- Démo en ligne hébergée (Render, Vercel…)
- Vidéo explicative ou pitch technique

---

## ✅ À faire

- [ ] Choisir un sujet pertinent (ex : assistant IA, tableau de bord, recommandateur)
- [ ] Rassembler le code dans un dépôt GitHub organisé
- [ ] Ajouter README, vidéo, instructions d’installation
- [ ] Intégrer dans un portfolio personnel
