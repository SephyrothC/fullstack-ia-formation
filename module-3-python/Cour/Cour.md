# 📘 Cours : Introduction à Python

## 🚀 Prérequis

* Aucun ! Python est idéal pour débuter.

## 🔧 Installation rapide

* 1 : Installer Python depuis [python.org](https://www.python.org)

## 📌 Concepts clés

### 1. Syntaxe de base

```python
print("Hello, World!")
```

### 2. Variables et types

```python
name = "Alice"
age = 30
pi = 3.14
```

### 3. Fonctions

```python
def saluer(nom):
    print(f"Bonjour {nom} !")
```

### 4. Conditions

```python
if age >= 18:
    print("Majeur")
else:
    print("Mineur")
```

### 5. Boucles

```python
for i in range(5):
    print(i)
```

### 6. Listes et dictionnaires

```python
courses = ["math", "info", "bio"]
infos = {"nom": "Luc", "age": 22}
```

### 7. Modules utiles

```python
import math
print(math.sqrt(25))
```
